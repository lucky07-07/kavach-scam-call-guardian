Eight agents, one job

During the call, agents 1–7 run in a fixed order. Evon argues; the verdict is decided by code, never by the LLM.

1ListenerGnani Prisma

Transcribes the call and separates the caller from the listener.

2ProsecutorGnani Evon

Lists the scam tactics, quoting the caller.

3DefenderGnani Evon

Lists signs the call is genuine.

4JudgeCode

Counts a claim only if the caller's own words prove it, and it isn't negated.

5GuardianEvon + Timbre

Warns the listener in Telugu or Hindi, and alerts the family with a voice note.

6ReporterGnani Evon

Drafts the complaint for the 1930 cybercrime helpline.

7NotarySHA-256 · Bitcoin

Seals the evidence in a hash chain, timestamped with OpenTimestamps.

8Family assistantEvon over MCP

After the call, answers the family's questions from the sealed evidence.

Why it can be trusted

  • The LLM argues; code decides. An LLM judge flagged every genuine call. With the prosecutor/defender split and a code Judge, no genuine test call has been flagged since.
  • The caller's words never reach the listener. Warnings and alerts are built only from verified tactics.
  • Only a 32-byte hash leaves the device. A one-byte edit fails verification against the Bitcoin block.

Limits and next steps

  • Calls are analysed after recording. Next: streaming Prisma, for warnings during the call.
  • Family alerts are built, voiced and queued; no SMS/WhatsApp gateway is connected yet.
  • All test calls are synthetic. Next: more Indian languages and a pilot with real families.
